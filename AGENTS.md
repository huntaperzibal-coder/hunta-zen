# hunta-zen

Личный блог «Гена и Винни», PHP 8.2+ и SQLite. Основной сценарий: черновик → сайт → Telegram. Сохраняй простоту личной работы.

- Репозиторий altai-topo используется только для чтения. Не изменять его.
- Код хранится в Git; storage, база, фотографии и секреты — только вне Git.
- До обновления существующей базы делай проверенный снимок. Не удаляй старые копии автоматически.
- Никогда не отправляй тестовые сообщения в настоящий Telegram-канал без прямого запроса.
- Каждый изменяющий HTTP-запрос требует входа и CSRF. Не полагайся на SameSite как замену CSRF.
- Публичные запросы не должны показывать черновики или их фотографии.
- При сохранении проверяй revision. Не перезаписывай чужое изменение молча.
- Перед коммитом: PHP lint, tests/core.php, tests/auth.php, tests/rich_text.php, tests/categories.php, tests/integration_http.py, node --check public/assets/js/editor.js.
- Перед обновлением main перечитай текущий head. Не используй force и не затирай параллельные изменения.

Вход адаптирован из Орды ТОПО. Сохраняй прежние аккаунты и пароли пользователя; не навязывай новый пароль или собственный минимум длины. Исходный сайт — только чтение.
